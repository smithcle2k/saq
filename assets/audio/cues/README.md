# Spoken cue clips

Supply these files when ready:

- `go.wav`
- `left.wav`
- `right.wav`
- `run.wav`
- `come-back.wav`

Use PCM WAV, mono, 16-bit, 44.1 kHz. Trim leading and trailing silence, match perceived loudness, and avoid clipping. Until static imports are added in `utils/cueAudioAssets.ts`, the app safely falls back to text-to-speech.
